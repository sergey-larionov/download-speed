# download-speed

Консольный скрипт на Node.js для замера скорости скачивания. Делает 10 последовательных запросов к указанному адресу, для каждого дожидается полного ответа, после чего считает среднее время запроса, общий объём скачанных данных и скорость.

Внешних зависимостей нет — используется встроенный в Node.js `fetch`.

## Требования

Node.js 18 или новее (проверить: `node -v`).

## Запуск

```bash
git clone https://github.com/sergey-larionov/download-speed.git
cd download-speed
node speedtest.js "<url>"
```

Пример (картинка ~15 MB):

```bash
node speedtest.js "https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg"
```

> URL лучше брать в кавычки. Для адреса из примера они не обязательны, но если в URL есть `?` или `&` (например, `https://example.com/file?id=1&size=big`), без кавычек bash, PowerShell и cmd обрежут адрес на `&` и воспримут остаток как отдельную команду.

Количество запросов можно изменить флагом `-n` (по умолчанию 10):

```bash
node speedtest.js "https://example.com/big.jpg" -n 5
```

Также работает `npm start -- "<url>"`.

## Пример вывода

```
URL: https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
Запросов: 10 (последовательно)

# 1      14.68 MB     8111.3 ms      1.81 MB/s
# 2      14.68 MB     7732.9 ms      1.90 MB/s
...
#10      14.68 MB     6843.9 ms      2.14 MB/s

──────────── Итог ────────────
Скачано всего:   146.79 MB (146794740 байт)
Среднее время:   7407.7 ms на запрос
Скорость:        1.98 MB/s (15.85 Мбит/с)
```

## Единицы измерения

| Величина      | Единица | Пояснение |
|---------------|---------|-----------|
| Объём         | **MB** (мегабайт) | десятичный: 1 MB = 1 000 000 байт; в итоге дополнительно выводится точное число байт |
| Время         | **ms** (миллисекунды) | от отправки запроса до получения последнего байта тела ответа |
| Скорость      | **MB/s** (мегабайт в секунду) | основная единица; в скобках та же скорость в **Мбит/с** (MB/s × 8) — в них обычно указывают скорость интернета провайдеры |

Итоговая скорость = общий объём / суммарное время всех запросов.

## Как считается

- Запросы идут строго по очереди: следующий начинается только после того, как полностью получено тело предыдущего.
- Время каждого запроса включает установку соединения, ожидание ответа и скачивание всего тела. Первый запрос обычно медленнее остальных: на нём устанавливается TCP/TLS‑соединение, дальше оно переиспользуется.
- Отправляется заголовок `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и считались реально переданные байты.
- Отправляется `Cache-Control: no-cache`, чтобы промежуточные кэши не подсовывали сохранённую копию.
- Редиректы проходятся автоматически.
- Если сервер ответил ошибкой (не 2xx) или запрос не удался, скрипт печатает причину и завершается с кодом 1. Неверные аргументы дают код 2.
